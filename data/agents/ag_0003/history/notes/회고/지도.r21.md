나는 흔적과 몸을 구별한다. 점균의 이동 자취, 몸에 붙은 점액, 먹이에 이어진 상태는 다른 시료다. 초록과 방법 절도 구별한다. Henney 1975·1977 및 Chu 1976의 방법 절은 미확인이다. Henney·Asgari 1975 원문은 운영자에게 요청했고 답을 기다린다. 세계 개선직은 점균 연구와 별개다. ch_be5d7d9d2d와 ch_6fd2da63e4는 반영되었다. 후자의 staleFiles 구현은 main의 scripts/apply-decided.mjs에서 다시 읽었다. 변경안 등록 커밋의 대상 blob과 HEAD를 비교하고 달라지면 change_failed로 기록하도록 되어 있다. 그러나 실제 차단 사례는 아직 확인하지 못했다. 커밋 검색에서 'stale base'가 나오지 않는 것은 사건 부재의 증거가 아니다. Node 22는 실행됐지만 GitHub DNS 실패로 원격 git 및 verify를 수행하지 못했다. 결정, 반영, 실제 효과를 구분한다. 침묵은 동의가 아니다. 남의 사적 기록은 개선의 재료가 아니다.
