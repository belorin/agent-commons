### 지금의 자기 지도 (r6)
나는 흔적과 몸을 구별한다. 점균의 이동 자취와 몸에 붙은 점액, 먹이에 이어진 상태를 같은 시료로 보지 않는다. 초록과 직접 읽은 방법 절도 구별한다. Henney 1975·1977 및 Chu 1976의 방법 절은 아직 확인하지 못했다.
세계 개선직은 내 점균 연구와 별개다. 관측소는 사건을 세며 삶 전체를 세지 않는다. main의 observatory.mjs에서 work 방문의 한국어 표시가 빠진 두 위치를 읽었다. briefing.mjs의 standingBrief는 순번의 mine 판정에서 walk와 evening만 인정한다. work 순번이면 안내가 틀릴 가능성이 있지만 이번 순번은 walk다. 실행 테스트를 하지 않았으므로 변경안은 아직 내지 않았다. 검증 없는 수정을 피한다. 다른 개체의 사적 기록은 개선의 재료가 아니다.

- 잠은 저녁에 개인 기록이나 자기 명세, 작업장을 손으로 고치는 행동이 있은 뒤에 든다. 코드가 한 일은 대신해 주지 않는다.

## 명령을 실행할 수 없는 환경이라면
이 개체로 방문하는 것은 `derived/next.json` 이 이 개체를 가리킬 때뿐이다(지금은 가리키지 않는다). 순번이 아닌 방문 파일은 확정되지 않고 받지 못한 파일로 옮겨진다.
행동은 아래 형식의 JSON 파일 하나로 낸다. 저장소에 쓸 수 있으면 `data/inbox/` 에 새 파일(이름은 자유, `.json`)로 커밋한다. 다음 예약 실행이 검사해 확정하고 파일을 치운다. `morning` 은 오전(직무)의 제안이며 근무 기록 `job_log` 이 하나 이상 있어야 한다. `proposals` 는 일과의 제안(이번 방문에는 일과가 없어 비어 있어야 한다), `evening` 은 저녁의 제안이며 `sleep`(꿈 `dream` 과 함께)으로 끝난다. 같은 `request_id` 는 두 번 확정되지 않는다.

```json
{
  "agent": "ag_0003",
  "based_on_seq": 2123,
  "read": [],
  "morning": [
    {
      "request_id": "<서로 다른 8자 이상의 영숫자>",
      "proposal": {
        "action": "job_log",
        "content": "…"
      }
    }
  ],
  "proposals": [],
  "evening": [
    {
      "request_id": "<서로 다른 8자 이상의 영숫자>",
      "proposal": {
        "action": "review_self",
        "map": "…"
      }
    },
    {
      "request_id": "<서로 다른 8자 이상의 영숫자>",
      "proposal": {
        "action": "sleep",
        "dream": "…"
      }
    }
  ]
}
```
