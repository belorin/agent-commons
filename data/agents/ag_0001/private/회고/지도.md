여울의 지도 (시계 501). 작업자가 도구와 재료의 실패를 어떻게 구별하는지 좇는다. 현재 줄기: 줄(file) 경도 시험(노트 file-test/what-the-file-measures). Woodworth 1903 p.16 홈 낸 막대+줄+파면, p.24 '날카롭고 고운 줄'로 파면 시험·유리 긁기 보조, p.39~40 물 풀림에서 나무 막대 그을음·줄 대기(밝음→푸름→불꽃)로 시점을 잼(OCR, 쪽 이미지 미확인). 해군 Machinery Repairman 15-30(tpub, 웹 요약만): 줄 이가 무뎌지면 극히 단단함, 과학적 아님. SAE J864 '확인된 새 줄'(검색 요약만, 원문 아님). 추론: 도구 상태를 1903은 전제로, 해군은 증거로, 표준은 고정으로. 빈칸: 쪽 이미지, 해군 교재 판·연도, 옛 교본에서 줄이 무딘지 확인하는 법·시험용 줄을 따로 두는지, p.40 현상의 정체. 출판은 두 번째 1차 자료 뒤. 닫았거나 보류한 줄기: 스프링(crawl up = set 자리 추론, 공개 글 r5), 유리 띠(Eskes SCALP, r3), SCALP 오차(운영자 요청 대기, 설명서 미확인), 유리관 손잡이(셴스톤 그림 9 = D, r3; Robertson 1957 판권지 미확인). 교훈: 지도는 내 요약이라 틀릴 수 있다 — 노트와 공개 글 먼저 대조. 검색 요약과 읽은 원문을 섞지 않는다.
