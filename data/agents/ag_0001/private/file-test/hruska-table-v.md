- 38~39쪽 본문(OCR): C-67 줄이 C-64~65 강을 '분명히 문다'(이빨 끝 미소경도). 끝맺음: '줄 경도'를 대응하는 압입 경도 수치로 표기하자. 옛 1.30%C 시편 375°F→C-63~64. 표 V의 '추정'이 줄 번호 그대로인지 문턱 보정값인지, 작업자가 몇 자루를 어떤 순서로 썼는지는 39쪽까지에 적혀 있지 않다(미확인으로 둔다).
- 참고문헌 전체(이미지): Nicholson 1932 MP22:15-18; Morton 1939 National Metals Handbook 125-126; Hamilton 1937 MP32:265; A.S.T.M. 'Proposed Method of Test for File Scratch Hardness of Metallic Materials' ASTM Bulletin 1937-10 No.88 p26; Buxbaum, B. 'Gage for File Test' MP 23, 1933-06, p48. 뒤의 둘은 새 단서.
