Bernhardt 1949: Barba를 '썼다'로 옮긴 다른 줄 (시계 569).

질문: Hruska 1942 말고 Barba를 경도 시험의 앞자리에 둔 글이 있는가. 있다면 '그가 줄로 시험했다'(Hruska)와 같은 꼴인가.

1) 찾은 것 (이미지로 확인)
- Ernest C. Bernhardt, "A History of Hardness Tests Based on Scratch Resistance Measurements", ASTM Bulletin no.157, March 1949, 49쪽(TP41). https://archive.org/details/sim_american-society-for-testing-and-materials-proceedings_1949-03_157 , 쪽 이미지 page/n48_w1600.jpg 를 직접 봄.
- 지은이: University of Delaware 화학공학 연구원(현 Monsanto 플라스틱 부문). 각주 1: 플라스틱 긁힘 저항 연구의 예비 조사로 엮은 역사(Modern Plastics 1948-10 글의 일부).
- 해당 문장: 'One of the first scratch tests recorded in the literature is that of Fr. A. Barba in 1640 who wrote: "Hardness is such a property of precious stones that those which a file can scratch are not so classed" (9).'
- 참고문헌 (9)(OCR로 읽음): O'Neill, "The Hardness of Metals and Its Measurement", Chapman and Hall, London, 1934.
- 다음 문단: Reaumur 1722, Werner 1774, Hauy 1801, Mohs 1822, 프라하 공대 1882 등. 줄 시험 자체(제조사·ASTM 1937)는 이 쪽에 없음(1쪽만 봄).

2) 대조 (사실)
- 인용문은 Douglass·Mathewson 1923 역('such a special Property … that those which a file can scratch are not so classed')과 거의 같다. 'special'이 빠졌다.
- 연도 1640(마드리드 출판 해), 동사 'wrote'. Hruska 1942의 '1637 published'·'he used the file scratch test'와 다르다. 분류 기준을 기준으로 옮겼다.
- 다만 Bernhardt도 이것을 'scratch test recorded'라 부른다. 기준 문장을 '시험의 기록'으로 세는 틀은 Hruska와 같다. 행위자를 넣지 않았을 뿐이다.

3) 같은 문장의 다른 자리 (스니펫만)
- O'Neill 1967(2판, Hardness Measurement of Metals and Alloys) fts 스니펫: 'In 1640 Barba wrote that "hardness is such a property of precious stones that those which a file can scratch are not so classed".' 본문은 대출 제한(401). 1934 초판에 같은 문장이 있는지는 미확인 — Bernhardt가 (9)를 붙였다는 것이 정황일 뿐.
- Journal of the Medical Association of Georgia 47(1958) 서평(Keeney, Lens Materials in the Prevention of Eye Injuries): 'the first definitions of hardness, formulated in 1640 by A. Barba' + 같은 인용. 서평자의 요약이지 Keeney 본문은 안 봄.

4) 판단 (추론)
- 경로가 둘로 보인다. (가) 1923 역 → O'Neill 1934(?) → Bernhardt 1949 → O'Neill 1967, Keeney 1958: 1640·'wrote'·인용 보존. (나) Hruska 1942: 1637·'he used'·인용 없이 바꿔 씀.
- Hruska 참고문헌에는 O'Neill 1934가 없다(Nicholson 1932, Morton 1939, Hamilton 1937, ASTM 제안만). 그러니 Hruska가 (가)를 거쳤는지는 이 기록으로 말할 수 없다. Morton 1939(Metals Handbook)는 archive.org에서 대출 제한(bwb_C0-BNZ-469, 401)이라 못 봄.
- 두 줄을 '전달 계보'로 묶는 것은 아직 내 짐작이다. 같은 1923 역을 각자 본 것일 수도 있다.
