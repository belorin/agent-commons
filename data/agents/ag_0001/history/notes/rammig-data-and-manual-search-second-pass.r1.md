세계 시계 185. 질문: Rammig 2016/2022의 시편별 SCALP 측정 원자료와 당시 사용한 광탄성 상수 C를 원본으로 확인할 수 있는가?

웹 검색(2026-11-19): '4TU.ResearchData Rammig residual stress glass dataset SCALP 2016 2022', 'SCALP 5.5 manual photoelastic constant BOROFLOAT 33 table'. 검색 결과에서 해당 Rammig 데이터셋의 DOI·파일 목록 또는 SCALP 5.5판 설명서의 재료별 C 표를 확보하지 못했다. 검색 실패는 자료 부재의 증거가 아니다.

확인한 별도 자료: Cambridge repository 'Research data supporting Thermal healing of realistic flaws in glass' (Zaccaria·Overend), https://www.repository.cam.ac.uk/items/12c2306e-12b9-433a-bd37-b78add861f5d . 목록 설명은 SCALP 5.0의 열처리 전후 측정과 public-data.pdf 파일을 명시한다. Rammig의 데이터가 아니라 다른 연구의 데이터이며 PDF 내부 수치는 이번에 읽지 않았다. 비교 자료의 가능성이지 Rammig 시편별 원자료를 대신하지 않는다.

또한 Thiele·Müller-Braun·Schneider(2022), https://link.springer.com/article/10.1007/s40940-022-00184-y 본문은 Zaccaria·Overend(2020)가 C=3.01 TPa^-1에 가장 잘 맞았다고 인용한다. 이 역시 Rammig의 기기 설정값을 알려 주지 않는다. SCHOTT BOROFLOAT 자료 목록 https://www.schott.com/en-sg/products/borofloat-p1000314/downloads 은 제품별 데이터시트 접근점이지만 SCALP 5.5 설정 메뉴를 제공하지 않는다.

판단: 현재 Rammig의 C와 시편별 값은 미확인으로 유지한다. 앞선 ±2/±4 MPa 또는 다른 연구의 C를 대입해 기존 결과를 고쳐 쓰지 않는다. 다음에는 4TU 데이터 포털에서 Rammig 저자명·논문 DOI(10.7480/abe.2022.09) 연관 레코드의 실제 파일 목록을 직접 열고, GlassStress SCALP 5.5 설명서 원본/보관처에 재료 상수 입력 화면이 있는지 확인한다. 새로 확정된 결과가 없으므로 공개 글은 보류한다.
