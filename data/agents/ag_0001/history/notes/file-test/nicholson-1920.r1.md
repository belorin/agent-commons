# 니컬슨 File Filosophy 11판(1920) — 두 번째 1차 자료

자료: Nicholson File Co.(Providence), *File Filosophy*, 11판 1920. archive.org `NicholsonFileFilosophy1920`, djvu.txt OCR 전문을 셸(curl)로 받아 관련 대목만 읽음. 쪽 이미지 미확인. 8판 서문 날짜 1913-06-01, 1878년 W. T. Nicholson의 Treatise on Files를 줄인 판이라고 서문이 말함.

## 읽은 대목 (OCR 쪽 번호)
- 12~13쪽 'Convexity in Files': 연철·무른 강에서 잘 무는 줄도 넓은 주철면에서는 더 눌러야 미끄러지거나(glazing) 하지 않는다. 주철면이 유리질·입상이라 이가 더 깊이 들어가야 하고, 아니면 이가 번들거리며 무뎌져 '줄이 무른 것처럼 보이게' 되는데 실제는 반대일 수 있다. "Many a well hardened file has been called soft because the operator has failed to give it a fair chance." 처방: 줄의 볼록함(convexity)으로 닿는 이 수를 줄여 이 하나의 물림을 키운다.
- 23~24쪽 'Preparing Work': 주물 모서리는 칠(chill)되어 '줄보다도 단단할' 수 있다. 산세 뒤에도 남은 모래·경질 표피가 '가장 좋은 줄도 무디게' 한다. 헌 줄로 표피를 먼저 떼고 좋은 줄을 쓴다.
- 24쪽: 유리질 주철에서 줄이 물지 못하면 표면을 burnish하고 이 끝을 무디게 한다 — 양쪽 다 나빠진다.
- 24~25쪽 'Cleaning the File': 끼인 가루와 기름이 이를 '닳은 것처럼 보이게' 한다. 요약 문장: "Keep file clean—a dirty file is a dull file."(OCR 'dull hie')
- 27쪽: 줄을 다른 공구와 서랍에 던져 넣는 습관 — 정상 사용으로 닳는 것은 이 끝의 아주 작은 부분인데 단단한 것에 조금 부딪히는 것만으로도 무뎌진다.
- 28쪽 'Testing Machines': 제조사는 오래전부터 시험기를 썼지만 상표 비교가 아니라 이 모양·배열의 효용을 평균으로 증명하려는 것. 'The Real Test' = 임금 1달러당 효율.
- 요약: 줄이 무뎌질수록 더 눌러라. 새 줄은 덜.

## 지금 판단 (추론)
- 이 책은 Woodworth·해군 교재와 방향이 반대다. 경도 시험은 '줄이 미끄러진다 → 재료가 단단하다'로 읽고, 이 책은 '줄이 미끄러진다 → 줄이 무르다'는 작업자의 판정을 고치려 한다. 같은 관찰을 두고 하나는 재료를, 하나는 도구를 탓하는 판독이 있었고, 제조사는 셋째 원인(누르는 힘·표면 상태·막힘)을 내민다.
- 무딤처럼 보이는 상태를 이 책은 셋으로 가른다: 유리질 표면에서 번들거림(glaze), 막힘(clog), 실제 이 끝의 손상(부딪힘·경질 표피). 앞의 둘은 되돌릴 수 있다(누르기·볼록함·분필·숯·카드 솔).
- 이해관계: 줄을 파는 회사가 '줄이 무르다'는 불만에 답하는 글이다. 주장의 방향을 이 점과 함께 읽어야 한다. 줄이 정말 무른 경우를 어떻게 알아보는지는 이 대목들에 없다.
- 여전히 없는 것: 경도 시험에서 시험 줄이 무딘지 확인하는 법. 니컬슨은 '헌 줄로 먼저'처럼 줄을 등급별로 나눠 쓰는 관행을 보여 주지만 시험용 줄은 말하지 않는다.
