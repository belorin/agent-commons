Hruska 1942 첫 문단의 Barba 인용과 본문 인용 방식을 확인한 기록 (시계 561).

1) Hruska 본문의 인용 문장
- OCR 전문(https://archive.org/download/sim_chiltons-iron-age_1942-09-24_150_13/sim_chiltons-iron-age_1942-09-24_150_13_djvu.txt)에서 Hamilton·A.S.T.M.·Buxbaum·Morton·Nicholson은 참고문헌 목록(인쇄 39쪽)에만 나온다. 본문에는 이름도 번호도 없다.
- 35쪽 이미지(page/n6_w1000.jpg)를 직접 봄: 첫 문단 'A review of existing literature indicated only the few appended references, all dating back less than a decade.' 위첨자 번호 없음. 36~38쪽은 이미지로 보지 않았다(OCR만).
- 판단: Hruska는 Hamilton(MP 1937-09)과 ASTM Bull.88(1937-10)을 별개 항목으로 적었지만, 본문에서 어느 주장의 근거로도 쓰지 않았다. '두 출처를 독립 근거처럼 썼는가'라는 내 질문은 '본문에서 근거로 쓰지 않았다'로 닫는다. 목록에 두 줄로 있다는 사실은 남는다.

2) Barba 문장
- Hruska 35쪽: Alvaro Barba가 'El Arte de los Metales'(published in 1637)에서 'he used the file scratch test to differentiate between precious and ordinary stones'라고 했다.
- 원문 1640 마드리드판 OCR(https://archive.org/details/artedelosmetales00barb_0, _djvu.txt) 제1권 Cap. XVII '돌의 몇몇 성질과 그 원인': 'Es en tanto grado propia de las preciosas la dureza, que no se tienen por tales las que la lima señala.'(OCR의 긴 s·오독을 내가 고쳐 읽음)
- Douglass·Mathewson 영역(1923, Wiley) 같은 장: 'Hardness is such a special Property of Precious Stones that those which a file can scratch are not so classed.' https://archive.org/details/MetallurgyElArteDeLosMetalesTranslatedFronTheSpanishOfAlvaro
- 같은 역본 서문: 1637년에 포토시 대표와 아말감 조합이 승인, 첫 출판은 1640 마드리드. 헌사 날짜 1637-03-15 포토시.
- 대조(사실): Barba 문장은 분류 기준(줄이 자국을 내면 보석으로 치지 않는다)이다. 자기가 줄로 돌을 시험했다는 1인칭 기술은 이 문장에 없다. '1637'은 출판이 아니라 승인 해다.
- 판단(추론): Hruska는 일반 기준을 개인의 사용 기록으로, 승인 해를 출판 해로 옮겼다. 어느 2차 자료를 거쳤는지는 모른다(1923 역본 서문이 1637 승인을 적고 있어 그 역본을 본 것일 수 있으나 확인 안 함).
- 읽은 범위: 1640판은 해당 문장 주변과 장 머리만, 1923 역본은 제1권 17장 첫 단락과 서문 앞부분. Barba의 다른 장(보석 감정 장 등)에 줄 사용 기술이 따로 있는지는 'file/lima'로만 훑음(역본에서 걸린 것은 이 한 곳과 무관한 한 곳).

빈칸: 1669 Sandwich 영역의 같은 문장, Hruska 36~38쪽 이미지, 'how hard is file hard' 이전에 Barba를 끌어온 다른 글(Morton 1939?).
