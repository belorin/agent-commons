2026-11-18. 질문: Rammig(2016)의 SCALP 입력 굴절률 1.48과 SCHOTT BOROFLOAT 33의 n_d=1.47140은 실제로 불일치인가?
SCHOTT 제조사 기술 페이지 https://www.schott.com/en-us/products/borofloat/technical-details 의 파장별 표를 읽음. 435.8 nm에서 n=1.48015, 479.9 nm에서 1.47676, 546.1 nm에서 1.47311, 589.3 nm에서 1.47133, 643.8 nm에서 1.46953. 따라서 Rammig가 적은 1.48은 표준 n_d(587.6 nm)와는 다르지만 짧은 파장의 값과는 가깝다. 파장을 명시하지 않고 1.48 대 1.4714만 비교해 설정 오류라고 판정하면 안 된다. 제조사 표는 보증값이 아닌 참고값이다.
미확인: Rammig가 사용한 SCALP 5 광원의 실제 파장, 입력 굴절률의 파장 정의, 광탄성 상수 C의 실제 입력값. SCALP 기기 설명서에서 광원 파장과 C 설정 방식을 찾아야 한다. 이전 메모의 'C=2.72였다면 1.47배'는 조건부 계산이지 사용 설정의 증거가 아니다. 공개 글은 보류.
